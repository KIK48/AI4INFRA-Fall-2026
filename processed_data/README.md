# processed_data/

Output of the Person 2 (LiDAR/Data Processing) preprocessing stage: ground/non-ground separated point clouds with height-above-ground, intensity, RGB, return information, run ID, and scanner ID preserved, plus original raw coordinates.

Name files using the internal run/scanner short codes plus a stage suffix, e.g. `R1_L_ground.las`, `R1_L_nonground.las` (see `raw_data/README.md` for the `R1_L`/`R1_R`/`R2_L`/`R2_R` mapping). LAS/LAZ files are gitignored.

**This folder is empty in the git repo.** The actual files live externally — see "Data Access" in the root `README.md` (location TBD).
