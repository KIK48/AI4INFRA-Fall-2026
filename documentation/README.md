# documentation/

Project documentation that isn't code:

- Coordinate reference system (CRS) — must be stated explicitly here
- Pipeline parameters and thresholds (or a pointer to the config file in scripts/)
- Decision log (date, what changed, why, who, old value, new value, result)
- Extraction/classification procedure — written so another team could repeat it on a different mile of roadway
- Validation/accuracy results (precision, recall, positional error)
